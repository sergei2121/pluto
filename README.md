# PLUTO — центр мониторинга инфраструктуры

Система мониторинга серверов, сетевых устройств и ПК. Серверная часть — Node.js в Docker (Ubuntu),
relay-агент — один Go-бинарник для Windows/Linux, телеметрия — через открытый Glances.

## Быстрый старт (сервер)

```bash
git clone https://github.com/pluto-monitor/pluto.git
cd pluto
cp .env.example .env          # при желании задайте ADMIN_PASSWORD
docker compose up -d --build  # консоль: http://<IP>:8080, витрина: http://<IP>:8081
```

Вход: `admin` / `pluto` (смените пароль в «Настройки → Пользователи»).

Проверка версии ядра: `curl -s http://localhost:8080/api/health`.

## Relay-агент (пинг устройств внутри VLAN/NAT)

Сервер не всегда видит устройства за NAT/VLAN. На такой ПК ставится `pluto-relay` — он пингует
локальные устройства по запросу ядра.

```bash
cd pluto-relay
GOOS=windows GOARCH=amd64 go build -o pluto-relay.exe .   # под Windows
pluto-relay.exe                                           # слушает :8091
```

В консоли: «Агенты → Добавить» → укажите IP ПК и адрес relay (`http://<IP-ПК>:8091`),
затем цели для пинга (IP, диапазон `10.0.0.1-20` или подсеть `10.0.0.0/24`).

## Glances (телеметрия CPU/GPU/RAM/диски/сеть/температуры)

```bash
glances -w    # Linux и Windows, веб-интерфейс на :61208
```

В консоли: «Агенты → Изменить» → укажите `http://<IP-ПК>:61208`. История хранится 30 дней,
графики — во вкладках «Статистика Bars» и «Статистика WS».

## Возможности

- Проверки: PING / HTTP / API / RTSP / SIP с кастомным интервалом, порогом аварии и детекцией деградации.
- Relay-пинги устройств, доступных только конкретному ПК.
- Телеметрия Glances: CPU по ядрам, GPU, RAM, диски, все сетевые адаптеры, температуры.
- Теги (10 цветов), быстрый поиск по IP/имени/тегу.
- Публичная витрина (отдельный порт, без входа): устройства + пинги агентов.
- Зеркало-ретранслятор: push снапшота на read-only копию в интернете.
- Роли: администратор и наблюдатель (ограниченный набор типов устройств).
- Уведомления: Telegram, e-mail, push в браузере.

## Структура

```
server/src/server.js   — ядро: проверки, планировщик, REST API, витрина, зеркало
server/src/lib.js      — хранилище (JSON), авторизация (scrypt + сессии)
pluto-relay/main.go    — relay-агент (Go, без зависимостей)
src/                   — веб-консоль (React + Vite + Tailwind)
```

Полная инструкция — в консоли: «Развёртывание».
