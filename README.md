# PLUTO — центр мониторинга инфраструктуры

Система мониторинга серверов, сетевых устройств и Windows-машин.
Серверная часть — Node.js в Docker (Ubuntu), агенты — один бинарник на Go для Windows.

## Быстрый старт (сервер)

```bash
git clone https://github.com/pluto-monitor/pluto.git
cd pluto
cp .env.example .env   # задайте DB_PASS, ADMIN_PASSWORD, JWT_SECRET
docker compose up -d
```

Консоль: `http://<хост>:8080`, вход `admin` / пароль из `.env` (по умолчанию `pluto` — смените сразу).

## Агент (Windows)

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://get.pluto.mon/agent.ps1 | iex"
pluto-agent.exe install --server wss://pluto.example.com:8443/ws --token <ТОКЕН>
net start pluto-agent
```

Токен выдаётся в консоли: **Агенты → Токен**. Агент собирает телеметрию каждые N секунд:

- загрузка и температура ЦП (WMI), количество ядер;
- ОЗУ: занято/всего, температура;
- диски: количество, объёмы, занятость, температуры;
- сетевые счётчики RX/TX по интерфейсам;
- ARP-скан доступных локальных сетей (подсети + найденные хосты).

## Возможности

| Проверка | Что делает |
|---|---|
| PING | ICMP-эхо с кастомным интервалом, порог аварии, фактор деградации |
| HTTP | запрос на хост:порт/путь, контроль кода и времени ответа |
| API | кастомная команда GET/POST с JSON-телом |
| RTSP | OPTIONS/DESCRIBE + контроль RTP-пакетов видеопотока |
| SIP | SIP OPTIONS keep-alive эндпоинтов |

- Роли: **администратор** и **наблюдатель** (просмотр активности разрешённых типов устройств).
- Теги: до 10 цветов, присваиваются устройствам, быстрый поиск по тегам и IP на главной.
- Уведомления: Telegram (Bot API), e-mail (SMTP), всплывающие окна браузера — каждое включается/выключается.
- Журнал событий: аварии, деградации (пинг выше базового в десятки раз), восстановления, агенты.

## Веб-консоль в этом репозитории

Каталог содержит React-консоль (Vite + Tailwind). В режиме `npm run dev` / собранной `dist/`
она работает со **встроенным ядром** (браузерная эмуляция опросов и телеметрии), что позволяет
осмотреть систему без сервера; в продакшене консоль подключается к REST/WS API ядра из `docker-compose.yml`.
