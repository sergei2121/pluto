# PLUTO — центр мониторинга инфраструктуры

Система мониторинга серверов, сетевых устройств и Windows-машин.
Серверная часть — Node.js в Docker (Ubuntu), агенты — один бинарник на Go для Windows.

## Быстрый старт (сервер)

```bash
git clone https://github.com/pluto-monitor/pluto.git
cd pluto
cp .env.example .env          # при желании задайте свой ADMIN_PASSWORD
docker compose up -d --build  # сервер собирается из исходников (server/, src/)
```

Консоль: `http://<хост>:8080`, вход `admin` / пароль из `.env` (по умолчанию `pluto` — смените сразу).
База — один файл `db.json` в томе `pluto-data`; полная инструкция — в [DEPLOY.md](DEPLOY.md).

Проверка, что ядро актуально (текущая версия **1.6.0**):

```bash
curl -s http://localhost:8080/api/health   # → {"ok":true,"version":"1.6.0",...}
```

Если консоль в браузере показывает «ядро: эмуляция» — образ устарел:
`git pull && docker compose up -d --build`, затем Ctrl+Shift+R.

## Агент (Windows)

```powershell
# сборка из исходников (Go 1.12+, один раз):
cd agent
go build -o pluto-agent.exe .

# на целевой машине (PowerShell, администратор):
mkdir C:\pluto
move pluto-agent.exe C:\pluto\pluto-agent.exe
cd C:\pluto
.\pluto-agent.exe -install -server ws://<IP-сервера>:8443/ws -token <ТОКЕН>
```

Токен выдаётся в консоли: **Агенты → Создать токен агента**. Агент собирает телеметрию:

- загрузка и температура ЦП (WMI), количество ядер;
- ОЗУ: занято/всего, температура;
- диски: количество, объёмы, занятость, температуры;
- сетевые счётчики RX/TX по интерфейсам;
- ARP-скан доступных локальных сетей (подсети + найденные хосты).

## Возможности

| Проверка | Что делает |
|---|---|
| PING | ICMP-эхо с кастомным интервалом, порог аварии, фактор деградации |
| HTTP | запрос на хост:порт/путь, контроль кода и времени ответа |
| API | кастомная команда GET/POST с JSON-телом |
| RTSP | OPTIONS/DESCRIBE видеопотока |
| SIP | SIP OPTIONS keep-alive эндпоинтов |

- Роли: **администратор** и **наблюдатель** (просмотр активности разрешённых типов устройств).
- Теги: до 10 цветов, присваиваются устройствам, быстрый поиск по тегам и IP на главной.
- Уведомления: Telegram (Bot API), e-mail (SMTP), всплывающие окна браузера — каждое включается/выключается.
- Журнал событий: аварии, деградации, восстановления, агенты.

## Веб-консоль

Каталог `src/` — React-консоль (Vite + Tailwind). В режиме `npm run dev` работает со
встроенным ядром (браузерная эмуляция опросов) — это позволяет осмотреть систему без сервера.
В продакшене консоль собирается в образ Docker и подключается к REST API ядра: как только
`/api/health` отвечает 200, интерфейс переключается на реальные данные (чип «ядро: сервер · v1.6.0»).
